## 👋 Sobre mí

```go
package main

type Dev struct {
	Usuario    string
	Desde      int
	Ahora      []string
	Stack      []string
	Escritorio string
}

func main() {
	marc := Dev{
		Usuario:    "MarcZX10", // antes MarcZX100
		Desde:      2020,
		Ahora:      []string{"AnyPS5", "MimOS", "MimOffice", "MapGarraf", "lmw"},
		Stack:      []string{"C++", "Go", "TypeScript", "JavaScript", "Python", "Lua"},
		Escritorio: "MimOS (Arch + KDE Plasma)",
	}
	_ = marc
}
```

- 🎮 **Contribuyo a [AnyPS5](https://github.com/boykopovar/AnyPS5)**, la herramienta que porta ejecutables de PS5 a Linux y Windows sin emulación. Soy **el #1 en PRs mergeados** y estoy en el top 5 por commits (datos de octubre de 2026).
- 🐧 **Trabajo en [MimOS](https://mimoslinux.org)**, una distro Linux de escritorio basada en Arch con KDE Plasma, hecha en España, y en **[MimOffice](https://github.com/MarcZX10/MimOffice)**, su suite ofimática.
- 🚌 Hago herramientas para problemas reales, como **[MapGarraf](https://github.com/MarcZX10/MapGarraf)**, un mapa comunitario del bus Vilanova ↔ Tarragona.
- 🤖 Llevo desde 2020 haciendo bots de Discord, herramientas para juegos de estrategia y alguna que otra locura.

### 🐧 MimOS + MimOffice
<a href="https://github.com/MarcZX10/MimOffice"><img src="https://github-readme-stats.vercel.app/api/pin/?username=MarcZX10&repo=MimOffice&theme=tokyonight&hide_border=true&bg_color=0d1117" alt="MimOffice" /></a>
